## 4. D1A (검사그룹 관리) 분석

### 4-1. 팝업 레이아웃

```
┌──────────────────────────────────────────────────┐
│ 툴바: [저장] [닫기]                                │
├──────────────────────────────────────────────────┤
│ 검사공정: [PROC_CODE]  검사항목: [INS_NAME]        │
│ 점검내역: [INS_DESC]                               │
├─────────────────────┬────────────────────────────┤
│ [선택된 그룹]       │ [그룹 목록]                  │
│                     │ 검사그룹명: [____] [검색]    │
│ ┌─────────────────┐ │ ┌──────────────────────────┐│
│ │ SEL│검사그룹명   │ │ │ SEL│검사그룹명           ││
│ │  □ │ 그룹A      │ │ │  □ │ 그룹B               ││
│ │  □ │ 그룹C      │ │ │  □ │ 그룹D               ││
│ └─────────────────┘ │ └──────────────────────────┘│
│ 더블클릭→오른쪽이동  │ 더블클릭→왼쪽이동           │
└─────────────────────┴────────────────────────────┘
```

### 4-2. 상단 정보 (ReadOnly)

| 필드      | 라벨      | 비고              |
|-----------|----------|-------------------|
| PROC_CODE | 검사공정  | 마스터 행에서 전달 |
| INS_NAME  | 검사항목명 | 마스터 행에서 전달 |
| INS_DESC  | 점검내역  | 마스터 행에서 전달 |

### 4-3. 좌측 그리드 (할당된 그룹) / 우측 그리드 (전체 그룹)

| ColumnName   | 헤더       | 타입      | 비고     |
|--------------|-----------|-----------|----------|
| INS_GRP_CODE | (hidden)  | string    | PK       |
| SEL          | 선택      | CheckEdit | 다중선택 |
| INS_GRP_NAME | 검사그룹명 | TextEdit  | 읽기전용 |

### 4-4. 동작 로직

- **초기 로드** (`QCT04A_SER2`): 좌측=이미 할당된 그룹 (RSLTDT), 우측=미할당 그룹 (RSLTDT2)
- **검색** (`QCT04A_SER3`): 우측 그리드 그룹명으로 필터링
- **더블클릭**: 좌→우 / 우→좌 이동
- **컨텍스트 메뉴**: 선택(SEL='1') 또는 포커스 행 이동
- **저장** (`QCT04A_INS2`): 기존 할당 전부 삭제 → 좌측 목록 재INSERT

## 5. 비즈니스 로직 (QCT04A.cs) 정리

| 메서드       | 대상 테이블                         | 동작                                                     |
|-------------|-------------------------------------|----------------------------------------------------------|
| QCT04A_SER  | TSTD_PROC_INS                       | 검사항목 조회 (PLT_CODE, PLANTS 기준)                      |
| QCT04A_SER2 | TSTD_INS_GRP_LIST + TSTD_PROC_INS   | D1A용: 할당그룹 + 미할당그룹 조회                          |
| QCT04A_SER3 | TSTD_PROC_INS                       | D1A용: 그룹명 검색 필터링                                  |
| QCT04A_INS  | TSTD_PROC_INS                       | UPSERT: INS_CODE 비어있으면 INSERT(채번), 있으면 UPDATE     |
| QCT04A_INS2 | TSTD_INS_GRP_LIST                   | D1A: 기존 삭제(DEL3) → 선택 항목 재INSERT                  |
| QCT04A_DEL  | TSTD_PROC_INS                       | 검사항목 삭제                                              |
| QCT04A_PROC | LSE_STD_PROC                        | 공정코드 드롭다운 데이터 조회 (ASSY/PROC 분기)              |

### 채번 규칙

- **INS_CODE**: `UTILITY_GET_SERIALNO(PLT_CODE, "INS", YYYYMMDD)` → 예: `INS20260227001`
