## 1. 개요

### 1.1 목적

본 문서는 MES 시스템 7개 메뉴의 C# WinForms → Java Web 전환 개발에 필요한 공수를 산정한다.
**전환(Migration) 프로젝트** 특성상 설계 단계를 최소화하고, AS-IS 분석 및 구현/포팅에 집중한다.

### 1.2 산정 기준

| 항목                 | 기준                                                    |
|----------------------|---------------------------------------------------------|
| 프로젝트 유형        | **전환(Migration/Conversion)**                          |
| 개발 방식            | 개발자 + Claude Code AI 협업                            |
| 1 Man-Day            | 8시간 기준                                              |
| 생산성 향상률        | 복잡도에 따라 40~55% 절감 (전환 프로젝트 특성 반영)     |
| 포함 범위            | AS-IS 분석, 구현/포팅, 단위테스트                       |
| 제외 범위            | 신규 설계, 통합테스트, 배포, 사용자 교육                |

[7] STD50A (작업자그룹) ───→ POP 계열 (작업자 할당)

[8] STD13A (부서/사원) ────→ 사원 마스터 참조하는 전체 화면
