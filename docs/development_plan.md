## 1. 프로젝트 개요

### 1.1 목적

AS-IS C# WinForms 기반 MES 시스템을 TO-BE Java Web (Spring MVC + MyBatis) 기반으로 전환

### 1.2 기술 스택

| 구분     | 기술                                       |
|----------|--------------------------------------------|
| Backend  | Java 1.8, Spring MVC, MyBatis, Apache CXF  |
| Frontend | JSP, jQuery, EasyUI                        |
| Database | MySQL                                      |
| Server   | Apache Tomcat 8.0                          |

### 1.3 AS-IS 소스 경로

```
C:\proActive\DecompiledSrc\
├── STD\STD\              # 기준정보 화면 (STDxxA_M0A.cs, STDxxA_D0A.cs)
├── ORD\ORD\              # 수주/생산계획 화면
├── CUBIZ_BR\             # 비즈니스 로직 (BRxxx\xxxA.cs)
└── CUBIZ_DA\             # 데이터 액세스 (Dxxx\Txxx_TABLE.cs, Txxx_TABLE_QUERY.cs)
```

## 3. 기술적 사전 분석

> **공수 산정 기준**
> - 기본 화면(JSP+JS): 8 MH
> - 팝업(JSP+JS): 4~8 MH (복잡도에 따라)
> - 탭 구조: +4 MH
> - 그리드 당: +2~4 MH
> - CRUD API: 1.5~2 MH per method
> - 특수 기능(엑셀, 캘린더, 시간검증 등): 4~12 MH
> - 마스터-디테일 연동: +4~6 MH

│  [7] STD50A ─────────→ POP 계열 (작업자 할당)                        │
│      (작업자그룹)                                                    │
│                                                                      │
│  [8] STD13A ─────────→ 전 시스템 (사원/부서 마스터 참조)             │
│      (부서/사원)          ↓ acEmpForm, acORG 공통 컴포넌트           │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**핵심 의존성**:
- **STD48A → STD49A**: STD49A의 비가동명 드롭다운이 STD48A의 TSTD_IDLECODE 참조
- **STD23A → 다수**: 휴일/CAPA 데이터가 생산계획, 보고서 등 10+ 화면에서 참조
- **STD13A → 다수**: TSTD_EMPLOYEE, TSTD_ORG가 전 시스템에서 참조

## 5. 공통 설계 패턴

### 5.1 DB 설계 패턴

| 항목            | 패턴                                             |
|-----------------|--------------------------------------------------|
| 복합 PK         | PLT_CODE (공장코드) + 각 화면별 고유 ID          |
| 논리 삭제       | DATA_FLAG (0=활성, 2=삭제)                       |
| 이력 관리       | REG_DATE/REG_EMP, MDFY_DATE/MDFY_EMP, DEL_DATE/DEL_EMP |
| 자동채번        | UTILITY_GET_SERIALNO() 함수 (접두어 + YYYYMMDD) |
| UPSERT 패턴     | SER(조회) → EXISTS? → INS/UPD                   |

```

### 5.3 MySQL 전환 패턴

| AS-IS (SQL Server)                                | TO-BE (MySQL)                                |
|---------------------------------------------------|----------------------------------------------|
| `GETDATE()`                                       | `NOW()`                                      |
| `CONVERT(nvarchar(8), GETDATE(), 112)`           | `DATE_FORMAT(NOW(), '%Y%m%d')`               |
| `DATEDIFF(MINUTE, START_TIME, END_TIME)`         | `TIMESTAMPDIFF(MINUTE, START_TIME, END_TIME)`|
| `ISNULL(A.END_TIME, GETDATE())`                  | `IFNULL(A.END_TIME, NOW())`                  |
